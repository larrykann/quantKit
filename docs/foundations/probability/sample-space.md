# Sample Space

The sample space is the set of all possible outcomes of a [[Random Experiments|random experiment]], denoted by $\Omega$ (omega). It represents the complete universe of everything that could possibly happen when conducting the experiment.

**Examples:**

- Single coin toss: $\Omega = \{\text{head}, \text{tail}\}$
- Two coins tossed simultaneously: $\Omega = \{(\text{head}, \text{head}), (\text{head}, \text{tail}), (\text{tail}, \text{head}), (\text{tail}, \text{tail})\}$
- Single die roll: $\Omega = \{1, 2, 3, 4, 5, 6\}$

**Financial Applications:**

- For "capture Pfizer stocks for a given time period": All possible stock prices that could be observed during that period form the sample space
- For "measure daily returns": All possible percentage return values form the sample space

The sample space provides the foundation for defining [[Events (Probability Theory)|events]] and calculating probabilities, as all events must be subsets of $\Omega$.
